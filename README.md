## Overview
This project is a simple web-based form that demonstrates how to use the native Constraint Validation API to validate user input without relying on external libraries. Users can fill out the form fields, and the application provides real-time validation feedback using built-in browser validation mechanisms. The form dynamically displays error messages, ensures data integrity, and offers a smooth and responsive user experience.

## Live Demo

Visit the website: [Live Demo](https://aderitomarrime.github.io/form-validation/)


## Features

- Minimal interface
- Clean and accessible form layout
- Native form validation using the Constraint Validation API
- Real-time validation feedback
- Custom error messages for invalid inputs
- Prevent form submission until all fields are valid
- Dynamic UI updates without page reload
- Simple and user-friendly interface

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

```sh
git clone https://github.com/aderitomarrime/form-validation.git
```

2. Navigate to the project 
```sh
cd form-validation
```
3. Open index.html in your browser


## How to use

1. Open the website in your browser
2. View the form with its input fields
3. nteract with the form:
    - Type into the fields to trigger real-time validation
    - Leave a field empty or enter invalid data to see error messages
    - Correct the input to clear the errors
4. Submit the form:
    - Fill in all required fields correctly
    - Click the "Submit" button
    - The form will only submit once all validation constraints are satisfied
